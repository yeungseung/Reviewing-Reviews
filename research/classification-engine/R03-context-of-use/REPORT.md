# R03 — Context-of-Use / Usability Evaluation Report

## 이 파일의 목적

이 파일은 실제 R03 연구가 시작된 뒤 사용자, 활동, 과업, 환경, 장비, 시간, 거리 및 조건에 따라 달라지는 제품 평가 구조에 관한 finding을 기록하는 report다. 현재는 작업공간 초기화 단계이므로 실제 외부 리서치 결과, source, evidence, candidate field는 기록하지 않는다.

## 작성 규칙

- 각 중요한 finding에는 `R03-E001` 형식의 `evidence_id`를 연결한다.
- User, Task, Activity, Environment, Equipment, measurement condition, subjective experience condition을 source의 정의에 따라 구분한다.
- 동일 Property의 상반된 평가가 Context 또는 Condition mismatch에서 비롯될 가능성을 Conflict와 분리해 검토한다.
- physical context와 social context, 객관적 측정과 주관적 경험을 혼합하지 않는다.
- 범용 Context structure와 특정 제품군·특정 usability method에 종속된 structure를 구분한다.
- Candidate Fields는 검토 후보일 뿐 최종 schema나 채택 결정이 아니다.

2. 이 분야가 해결하려는 문제

4. 핵심 Entity

6. Entity 간 관계
7. Context / Condition 표현 방식
8. 비교 가능성 / Conflict 처리

10. 실제 데이터 구조 또는 필드 사례

12. 수정해서 참고해야 하는 구조
13. 가져오면 안 되는 구조 / 한계
