# Design References

REVIEW²는 검증된 디자인 시스템을 참고하되,
각 회사의 자산이나 화면을 복제하지 않고 원칙과 구조만 채택한다.

## Apple

Role:
- restraint
- hierarchy
- familiarity
- content-first presentation
- quiet UI

Reference:
- https://developer.apple.com/design/human-interface-guidelines/

## Atlassian Design System

Role:
- spacing tokens
- 8px base unit
- 12-column grid
- proximity / hierarchy / rhythm

References:
- https://atlassian.design/foundations/spacing
- https://atlassian.design/foundations/grid

## IBM Carbon Design System

Role:
- 8px geometry
- data visualization
- chart selection
- axis / labels / legends
- information-dense layouts

References:
- https://carbondesignsystem.com/elements/2x-grid/overview/
- https://carbondesignsystem.com/data-visualization/chart-types/
- https://carbondesignsystem.com/data-visualization/axes-and-labels/
- https://carbondesignsystem.com/data-visualization/legends/
- https://carbondesignsystem.com/data-visualization/dashboards/

## Material Design

Role:
- motion duration logic
- entrance / exit / standard easing
- distance-aware motion

Reference:
- https://m1.material.io/motion/duration-easing.html
